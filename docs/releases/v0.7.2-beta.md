# Versión 0.7.2-beta: notas de versión

- **Fecha:** 3 de noviembre de 2026
- **Identificador:** `com.robotcentinela.app`, `versionCode` 8
- **Android:** 10 o superior (`minSdk` 29), `targetSdk` 36
- **Firma:** clave de depuración de Android (`CN=Android Debug`). Sirve para instalar y mostrar; **no** para publicar en una tienda.

## Qué cambia respecto a 0.7.1-beta

### Alertas en español
Los tipos que reporta el robot y el simulador del equipo se mostraban con su identificador en inglés (p. ej. «Robot flipped»).
Ahora tienen texto propio en la lista de eventos, el detalle, el aviso superior y la notificación:

| Tipo | Se muestra como |
|---|---|
| `gas_mq6` | Gas LP detectado (MQ-6) |
| `gas_mq4` / `gas_mq7` | Gas metano detectado (MQ-4) / Monóxido de carbono detectado (MQ-7) |
| `gas_emergency_hold` | Robot detenido por emergencia de gas |
| `robot_flipped` | Robot volcado |
| `robot_trapped` | Robot atascado |
| `cliff_front` / `cliff_rear` | Desnivel al frente / Desnivel detrás |
| `cliff_front_escape` / `cliff_rear_escape` | Maniobra de escape de desnivel frontal / trasero |
| `sensor_dht_fault` | Falla del sensor de temperatura y humedad (DHT22) |
| `sensor_error` | Error de sensor |
| `ultrasonic_evasion` | Evasión de obstáculo |
| `battery_low` | Batería baja |

Un tipo nuevo sin texto propio ya no aparece en inglés: se traduce palabra por palabra (p. ej. `motor_fault` → «Motor falla»).

### Deslizar hacia abajo para actualizar (Resumen)
En la pantalla **Resumen**, deslizar hacia abajo actualiza al momento las lecturas, las alertas y la misión, sin esperar el aviso en vivo
ni los sondeos de 10 s y 30 s. Se muestra el indicador circular estándar mientras se consulta. Si la conexión en vivo estaba caída, la app
lo sigue indicando aunque el refresco manual traiga datos.

## APK

| APK | Para qué sirve | Inicio de sesión |
|---|---|---|
| `RobotCentinela-0.7.2-beta.apk` | Flujo real de acceso | Sí; resolver requiere rol técnico |
| `RobotCentinela-0.7.2-beta-demo.apk` | Demostración con «Resolver» | No (rol `anon`); se adjunta a mano |

El APK `demo` lleva la clave de escritura temporal (ADR-011), que se salta RLS y se revoca al terminar la demostración. El `release` no la contiene.

- **No se ejecutaron** pruebas unitarias ni se probó en un teléfono, por indicación del equipo. El gesto de deslizar y los textos nuevos no se han visto en un dispositivo.
